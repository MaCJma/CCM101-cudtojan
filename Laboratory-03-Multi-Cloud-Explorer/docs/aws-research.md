# AWS Research & Platform Evaluation

## Brief Overview
Amazon Web Services (AWS) launched in 2006 as a pioneer in modern cloud computing. It offers the broadest selection of Infrastructure-as-a-Service (IaaS) and Platform-as-a-Service (PaaS) capabilities, helping companies scale applications globally with minimal upfront capital expenses.

## Global Infrastructure
AWS operates across a high-availability infrastructure network:
* **AWS Regions:** Geographic areas housing isolated datacenters.
* **Availability Zones (AZs):** One or more discrete data centers within a region with redundant power, networking, and connectivity.
* **Edge Locations:** Points of presence (PoP) designed to deliver content via CloudFront CDN with low latency.

## Cloud Management Console
The AWS Management Console provides a web-based, central interface to manage compute, storage, databases, and network assets, complete with robust IAM role delegation and billing monitoring.

## Four (4) Core Services
1. **Amazon EC2 (Elastic Compute Cloud):** Resizable, secure virtual server capacity in the cloud.
2. **Amazon S3 (Simple Storage Service):** Scalable object storage for files, backups, and analytics data.
3. **Amazon VPC (Virtual Private Cloud):** Logically isolated virtual network sections to launch AWS resources securely.
4. **AWS IAM (Identity and Access Management):** Controls access to AWS services and resources securely.

## Three (3) Advantages
* **Market Maturity & Ecosystem:** Has the largest marketplace of third-party tools and certified talent.
* **Massive Scalability:** Offers near-limitless resource capacity and global reach.
* **Feature Depth:** Contains over 200 fully featured services covering emerging technologies.

## Typical Enterprise Use Cases
* High-traffic global web and mobile application hosting.
* Large-scale data warehousing and big data processing pipelines.
* Enterprise application migrations and disaster recovery targets.

# Laboratory 01: Welcome to the Cloud

## Mission Overview
This activity introduces basic cloud playground environments, Linux system administration basics, file management, and GitHub documentation workflows.

## Objectives
- Deploy an Ubuntu Linux instance in a web-based playground.
- Practice user management, permission handling, and environment exploration.
- Document system specifications using Markdown.
- Version control laboratory outputs using Git and GitHub.

## Activities Performed
- Created a customized sudo user account.
- Inspected OS kernel, CPU, memory, and disk usage specs.
- Organized directory structures and formatted Markdown logs.
- Synchronized local assets to a remote GitHub repository.

## Linux Commands Used
- `useradd`, `passwd`, `usermod`, `su`
- `uname`, `lscpu`, `free`, `df`
- `mkdir`, `cp`, `cat`
- `git init`, `git add`, `git commit`, `git push`

## Skills Learned
- Linux command-line operations.
- User privilege administration.
- Markdown documentation formatting.
- Basic Git remote workflow management.

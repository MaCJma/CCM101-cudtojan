## Evaluation Questions & Answers

1. **Which cloud provider offers the broadest range of services?**
   Amazon Web Services (AWS) provides the broadest range of public cloud services, featuring over 200 fully-featured offerings. Its early entry into the market allowed it to establish deep functionality across compute, database, IoT, edge computing, and analytics workloads.

2. **Which provider best integrates with Microsoft technologies?**
   Microsoft Azure seamlessly integrates with existing Microsoft technologies. It offers native synchronization with Microsoft 365, Microsoft Entra ID, Windows Server environments, and licensing cost savings through Azure Hybrid Benefit.

3. **Which provider is strongest in Artificial Intelligence and Kubernetes?**
   Google Cloud Platform (GCP) is considered the industry leader in Artificial Intelligence and Kubernetes. Having originally created Kubernetes and pioneered AI search infrastructure, GCP provides advanced native solutions like Google Kubernetes Engine (GKE) and Vertex AI.

4. **Which cloud platform would you personally choose and why?**
   I would personally choose **AWS** because of its comprehensive documentation, huge global market share, and extensive community support. The platform's vast toolset and mature ecosystem ensure high flexibility regardless of the application architecture being built.

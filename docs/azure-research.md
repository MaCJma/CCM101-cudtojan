# Microsoft Azure Research & Platform Evaluation

## Brief Overview
Microsoft Azure, launched in 2010, is a leading cloud provider particularly favored by enterprises with existing Microsoft footprints. Azure excels in hybrid cloud integrations, enterprise software identity systems, and unified cloud-to-edge management.

## Global Infrastructure
Azure features a massive footprint with more regions globally than any other provider:
* **Regions:** Geographic boundaries containing clusters of interconnected datacenters.
* **Availability Zones:** Physically separate locations within an Azure region featuring independent power and cooling.
* **Azure ExpressRoute:** Dedicated private connections between on-premises datacenters and Azure.

## Cloud Management Console
The Azure Portal features a customizable, dashboard-driven user interface that lets administrators group resources into "Resource Groups" for unified billing, policy enforcement, and role access control.

## Four (4) Core Services
1. **Azure Virtual Machines:** Scalable on-demand compute infrastructure supporting Linux and Windows.
2. **Azure Blob Storage:** Massively scalable object storage for unstructured data and massive backups.
3. **Microsoft Entra ID (formerly Azure Active Directory):** Cloud-based identity management and single sign-on system.
4. **Azure SQL Database:** Fully managed, highly scalable relational database service based on MS SQL Server engine.

## Three (3) Advantages
* **Seamless Microsoft Integration:** Native support for Microsoft 365, Active Directory, and Windows Server licensing.
* **Hybrid Cloud Dominance:** Industry-leading hybrid services like Azure Arc and ExpressRoute.
* **Enterprise Cost Savings:** "Azure Hybrid Benefit" reduces cloud licensing costs for existing Windows Server and SQL Server users.

## Typical Enterprise Use Cases
* Hybrid cloud migration for legacy enterprise systems.
* Modernizing Windows-based enterprise applications.
* Centralized identity, access management, and Active Directory consolidation.
